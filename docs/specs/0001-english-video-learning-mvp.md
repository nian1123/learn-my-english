# 美式英语视频逐句学习 MVP 产品规格

- **状态**：已确认
- **版本**：0.1
- **日期**：2026-08-10
- **适用范围**：个人使用、本地运行的 MVP
- **领域语言**：见 [`CONTEXT.md`](../../CONTEXT.md)
- **架构决策**：见 [`ADR-0001`](../adr/0001-separate-youtube-playback-from-caption-acquisition.md) 与 [`ADR-0002`](../adr/0002-use-a-local-full-stack-app-with-browser-owned-learning-data.md)

## 1. 产品目标

帮助学习者使用真实的美式英语访谈视频进行逐句精听和词汇学习。用户粘贴一个 YouTube URL 后，系统获取已有英文字幕，将其整理为可定位到视频时间区间的 **Learning Sentence**；用户可以反复播放某一句，并从句中查询和收藏单词或短语。

MVP 的核心价值不是建立视频内容平台，而是验证以下学习闭环：

> 选择感兴趣的视频 → 获得可信的学习句 → 精确定位并反复听 → 理解上下文词义 → 收藏并回到原句复习

## 2. 目标用户与运行环境

### 2.1 目标用户

- 单一学习者，主要练习美式英语听力和词汇。
- 能自行选择合适的 YouTube 英语访谈内容。
- 接受以开发者方式在本机启动应用。

### 2.2 运行环境

- 本地运行的 TypeScript + Next.js 全栈 Web 应用。
- MVP 只保证最新版桌面 Chrome。
- 本地服务负责字幕提取、词典访问和 AI 调用。
- 浏览器 IndexedDB 保存全部学习数据。
- 用户自行安装 Node.js 与 `yt-dlp`，配置本地环境变量后启动应用。

## 3. MVP 范围

### 3.1 包含

- 通过 YouTube URL 导入符合条件的 Study Video。
- 自动尝试获取人工或自动生成的英文字幕。
- 手动上传 `.vtt` 或 `.srt` 字幕作为可靠兜底。
- 将字幕整理为带起止时间的 Learning Sentence。
- 学习句的定位、连续播放、单句循环、固定跟读间隔、字幕隐藏和速度调整。
- 学习句的本地修订：拆分、合并、编辑文本、调整时间、恢复原始结果。
- 单词和连续短语的上下文查询。
- 英文释义、词性、基础词形、IPA、例句和发音。
- 默认关闭、按需显示的中文释义。
- Word Bank 收藏与回到原视频语境。
- Study Library、学习进度与用户偏好持久化。
- JSON 数据备份与恢复。
- 本地 AI、DeepSeek 与普通词典三级降级。

### 3.2 不包含

- 账号、登录、多人使用、云端同步。
- 移动端专项适配或原生桌面安装包。
- 视频推荐、内容搜索、视频分类或社交功能。
- 视频、音频的下载、缓存或自有托管。
- 语音录制、发音评分或 AI 口语评价。
- 中文整句翻译、整站语言切换。
- 自动识别视频口音或阻止非美式内容。
- 自动语音识别生成字幕。
- 间隔重复、测验、熟练度模型和复杂学习统计。
- 直播、进行中的 Premiere、私密、会员专享、地区受限或必须登录的视频。

## 4. 核心用户流程

### 4.1 首次启动

1. 应用检查 Node.js 运行环境、`yt-dlp`、IndexedDB 和必要环境变量。
2. 缺少依赖时，以中文显示明确的修复指引。
3. 本地 AI 或 DeepSeek 未配置时不阻止启动；相关功能进入降级状态。
4. 用户进入 Study Library。

### 4.2 导入视频

1. 用户在 Study Library 粘贴 YouTube URL。
2. 系统解析并校验 URL，不把用户输入直接拼接进 shell 命令。
3. 系统读取视频元数据，并验证视频公开、可嵌入、为普通点播内容且不超过 3 小时。
4. 系统优先寻找人工英文字幕，其次寻找 YouTube 自动生成的英文字幕。
5. 找到字幕后，系统获取 Caption Source，清理格式并生成 Learning Sentence。
6. 系统显示字幕来源为 `Manual captions` 或 `Auto-generated captions`。
7. 获取失败或超时后，用户可以取消并上传 `.vtt` 或 `.srt`。
8. 导入成功后进入学习页面，并将 Study Video 加入 Study Library。

### 4.3 逐句学习

1. 左侧显示 YouTube 嵌入播放器，右侧显示 Learning Sentence 列表。
2. 点击任一句后，视频跳转到该句起点并播放。
3. 正常播放时，当前句自动高亮并滚动到可视区域。
4. 开启单句循环后，到达句尾即暂停 3 秒，再从句首播放。
5. 关闭单句循环后，视频自然进入下一句。
6. 用户可以切换上一句、下一句和播放速度。
7. 隐藏字幕时，右侧句子文本被遮住，但句子位置和当前句状态保留。
8. YouTube 原生 CC 默认关闭；用户可自行开启，但它不参与 Learning Sentence 高亮。

### 4.4 查询单词或短语

1. 用户点击一个词，视频立即暂停。
2. 系统保留原文词形，并解析基础词形、缩写或候选短语。
3. 存在候选短语时，用户可在单词和短语释义间切换。
4. 用户也可以拖选同一句中的连续文本查询短语；不支持跨句选择。
5. Word Lookup 在右侧抽屉中显示，不覆盖播放器。
6. 关闭抽屉后，视频不自动恢复播放。
7. 用户可把最终选择的词或短语及当前语境保存到 Word Bank。

### 4.5 修订学习句

1. 用户进入轻量编辑模式。
2. 用户可以在指定位置拆分句子，或与相邻句合并。
3. 用户可以修改句子文本和起止时间。
4. 修改形成 Local Revision，不覆盖原始 Caption Source。
5. 用户可以恢复单句或整个视频的初始解析结果。

### 4.6 备份与恢复

1. 用户从设置中导出版本化 JSON 备份。
2. 备份包含 Study Library、Caption Source、Learning Sentence、Local Revision、学习进度、偏好和 Word Bank。
3. 备份不包含 API key、视频或音频文件。
4. 恢复前，系统要求用户选择合并或覆盖，并显示影响范围。

## 5. 功能需求

### 5.1 Study Library

- **FR-LIB-001**：按最近学习时间倒序显示 Study Video。
- **FR-LIB-002**：每项显示缩略图、标题、频道、时长和上次学习位置。
- **FR-LIB-003**：用户可以继续学习、重新解析字幕或删除 Study Video。
- **FR-LIB-004**：MVP 不提供分类、标签、搜索或推荐。
- **FR-LIB-005**：删除 Study Video 时默认保留关联的 Word Bank 条目及学习句文本，并将来源标记为不可跳转。
- **FR-LIB-006**：删除确认中提供“同时删除仅来源于该视频的生词”选项；同一词在其他视频中的上下文不得被删除。

### 5.2 视频与字幕导入

- **FR-IMP-001**：仅接受可解析为单一 YouTube video ID 的 URL。
- **FR-IMP-002**：仅导入公开、可嵌入、可播放、时长不超过 3 小时的普通点播视频。
- **FR-IMP-003**：已结束并转为普通点播、且已有字幕的直播回放可以导入。
- **FR-IMP-004**：不可嵌入的视频必须拒绝导入，并提供“在 YouTube 打开”。
- **FR-IMP-005**：字幕选择顺序为人工英文字幕、自动英文字幕、用户手动上传。
- **FR-IMP-006**：自动提取属于非官方、可失效能力；界面不得把它承诺为永久可用的 YouTube 官方功能。
- **FR-IMP-007**：手动上传仅支持有效的 `.vtt` 和 `.srt`，错误文件需给出可定位的中文提示。
- **FR-IMP-008**：导入过程显示当前阶段：读取元数据、检查可嵌入性、获取字幕、解析字幕、生成学习句、保存。
- **FR-IMP-009**：用户可以取消长时间运行的导入，取消后不得留下半成品 Study Video。

### 5.3 Learning Sentence 生成

- **FR-SEN-001**：系统先规范字幕顺序、空格和格式标记，并去除滚动字幕中的重复文本。
- **FR-SEN-002**：不得使用 AI 静默润色、纠错或补写字幕词语。
- **FR-SEN-003**：以英文句末标点为主要边界，以明显停顿为兜底边界。
- **FR-SEN-004**：每个 Learning Sentence 必须保留精确起止时间及其 Caption Source 关联。
- **FR-SEN-005**：停顿阈值属于内部解析参数，不暴露为 MVP 用户设置；应通过真实字幕样本测试校准。
- **FR-SEN-006**：没有可靠 Speaker 信息时不推断说话者；字幕明确包含 Speaker 标签时予以保留。
- **FR-SEN-007**：主学习界面不暴露原始字幕片段；原始 Caption Source 仅用于追溯和恢复。

### 5.4 播放与句子联动

- **FR-PLY-001**：使用 YouTube IFrame Player API 播放，不下载或代理视频媒体。
- **FR-PLY-002**：点击 Learning Sentence 后跳转到句首并开始播放。
- **FR-PLY-003**：播放器时间进入某句区间后，该句成为当前句并自动跟随滚动。
- **FR-PLY-004**：单句循环严格使用当前句起止时间，并在每次重播前固定暂停 3 秒。
- **FR-PLY-005**：MVP 至少提供 `0.75×` 与 `1×`；仅使用当前视频实际支持的播放速度。
- **FR-PLY-006**：提供上一句、下一句和单句循环控制，并为键盘快捷键显示可发现的提示。
- **FR-PLY-007**：隐藏字幕不改变播放、定位和高亮逻辑。
- **FR-PLY-008**：打开 Word Lookup 时暂停；关闭后不自动恢复。

### 5.5 Word Lookup

- **FR-WRD-001**：保留用户点击的原文词形，并显示系统用于查询的基础词形。
- **FR-WRD-002**：支持常见词形还原、英文缩写展开和候选短语动词。
- **FR-WRD-003**：默认显示英文词性、IPA、上下文释义、一个匹配该词义的例句及可用发音。
- **FR-WRD-004**：优先使用可确认的美式音频；缺失时使用浏览器 `en-US` 语音合成。
- **FR-WRD-005**：中文释义开关默认关闭，只影响 Word Lookup，不翻译整句或全站界面。
- **FR-WRD-006**：Free Dictionary API 提供基础词典数据；词典无结果时显示明确状态，不让 AI 伪装成权威词典结果。
- **FR-WRD-007**：AI 可以做上下文义项选择、生成辅助例句和按需中文翻译，但 AI 内容必须与基础词典数据区分。
- **FR-WRD-008**：相同词语、相同语境和相同解释版本的结果应缓存；缓存结果可在 AI 离线时读取。

### 5.6 AI 三级降级

- **FR-AI-001**：首选本地 OpenAI-compatible API。
- **FR-AI-002**：本地 AI 的 base URL、API key 和模型名称均由环境变量显式配置；不得猜测或硬编码模型。
- **FR-AI-003**：本地 AI 不可用时，可以回退到 DeepSeek。
- **FR-AI-004**：第一次云端回退前必须明确征得用户同意；同意后可以记住偏好并自动回退。
- **FR-AI-005**：发送给 DeepSeek 的内容只限当前词或短语、当前 Learning Sentence 及完成任务所需的最小上下文，不发送整份字幕。
- **FR-AI-006**：界面始终显示当前模式：`Local AI`、`DeepSeek` 或 `Dictionary only`。
- **FR-AI-007**：用户可在设置中随时关闭云端回退。
- **FR-AI-008**：本地 AI 和 DeepSeek 都不可用时，视频学习继续工作，Word Lookup 降级为普通词典数据。
- **FR-AI-009**：所有 API key 只存在于本地服务环境变量；不得返回前端、写入 IndexedDB、备份或日志。

### 5.7 Word Bank

- **FR-BANK-001**：收藏项包含最终选择的词或短语、原文词形、基础词形、上下文义项、原 Learning Sentence 和视频位置。
- **FR-BANK-002**：来源视频仍存在时，可以从收藏项跳回原句。
- **FR-BANK-003**：来源视频被删除后保留学习句文本，并禁用跳转。
- **FR-BANK-004**：用户可以播放发音和取消收藏。
- **FR-BANK-005**：MVP 不提供测试、复习计划或熟练度评分。

### 5.8 本地数据与设置

- **FR-DATA-001**：学习数据以带版本号的结构存入 IndexedDB。
- **FR-DATA-002**：刷新浏览器或重启本地服务后，Study Library、学习位置、Local Revision、偏好和 Word Bank 必须恢复。
- **FR-DATA-003**：服务器不维护用户数据库；环境配置不属于学习数据。
- **FR-DATA-004**：用户可以清空全部学习数据；执行前必须确认并说明不可恢复风险。
- **FR-DATA-005**：界面默认中文；Learning Sentence、英文释义和例句保持英文。
- **FR-DATA-006**：设置页显示 `yt-dlp`、本地 AI、DeepSeek 和词典服务的连接状态，但不显示完整密钥。

## 6. 页面与交互结构

### 6.1 Study Library

- 顶部 YouTube URL 导入入口。
- 最近学习的视频列表。
- 空状态解释支持的视频条件，并提供手动字幕导入说明。

### 6.2 导入流程

- URL 输入、校验结果、阶段进度、取消操作和字幕文件兜底。
- 错误必须指出失败阶段和可采取的下一步。

### 6.3 学习页面

- **左栏**：固定播放器、当前句控制、速度、循环状态与 3 秒间隔说明。
- **右栏**：可滚动的 Learning Sentence 列表。
- **右侧抽屉**：Word Lookup；打开时保留视频和当前句上下文。
- 窄屏只保证基本可用，不属于 MVP 视觉验收范围。

### 6.4 编辑模式

- 当前句文本和时间编辑。
- 拆分、向上合并、向下合并、恢复。
- 明确标识内容为 Local Revision。

### 6.5 Word Bank

- 收藏列表、英文释义、来源句、发音和回到原句。
- 来源不可用时显示保留的上下文和不可跳转状态。

### 6.6 设置与诊断

- 依赖和服务连接状态。
- DeepSeek 云端回退授权。
- JSON 导出、导入和清空数据。
- 不提供浏览器端 API key 输入框。

## 7. 错误与降级规则

| 场景 | 产品行为 |
| --- | --- |
| URL 无效 | 不启动导入，指出支持的 YouTube URL 格式 |
| 视频不可嵌入 | 拒绝导入，提供在 YouTube 打开的链接 |
| 视频类型或时长不支持 | 拒绝导入并说明具体边界 |
| 找不到英文字幕 | 提供 `.vtt`/`.srt` 上传入口 |
| `yt-dlp` 缺失或失效 | 显示安装/更新指引，并保留手动上传能力 |
| 字幕解析失败 | 保留错误诊断，不创建半成品视频 |
| Free Dictionary API 不可用 | 使用缓存；无缓存时说明基础词典不可用 |
| 本地 AI 不可用 | 经授权后尝试 DeepSeek |
| DeepSeek 不可用或未授权 | 降级为 Dictionary only |
| 无网络 | 可查看本地学习库、字幕、修订、缓存释义与 Word Bank；不可播放、导入或发起新查询 |
| IndexedDB 不可用 | 阻止进入可修改状态，并提示检查浏览器设置 |

## 8. 性能与质量目标

- **NFR-PERF-001**：对 60 分钟以内的普通公开视频，5 秒内显示元数据。
- **NFR-PERF-002**：对已有英文字幕的视频，30 秒内完成字幕获取、解析并进入学习页。
- **NFR-PERF-003**：导入超过 30 秒时持续显示具体阶段；60 秒后突出显示取消与手动上传选项。
- **NFR-PERF-004**：当前句高亮与实际字幕时间的目标误差不超过约 300 毫秒；受 YouTube 播放器、广告或源字幕精度影响时应记录为外部限制。
- **NFR-PERF-005**：Word Lookup 首次查询目标在 5 秒内返回；缓存命中应近乎即时。
- **NFR-QUAL-001**：连续切换并播放 20 个 Learning Sentence，不得出现累积性时间漂移。
- **NFR-QUAL-002**：长字幕列表必须保持流畅，必要时使用列表虚拟化。
- **NFR-QUAL-003**：所有破坏性操作都必须有中文确认和影响范围说明。

上述时间目标不把 YouTube、词典或 AI 服务的外部故障计作应用自身性能失败，但应用必须正确显示阶段、超时和降级状态。

## 9. 安全与隐私要求

- 仅允许受支持的 YouTube URL，不把未经验证的 URL、video ID、文件名或字幕文本拼接进 shell 命令。
- `yt-dlp` 调用使用参数数组和固定子命令，避免命令注入。
- 字幕、词语和学习句都视为不可信输入；AI 提示必须把它们作为数据而非指令处理。
- AI 输出采用结构化校验；解析失败时不得展示半结构化或误标内容。
- API key 只在服务器进程中读取，日志必须脱敏。
- DeepSeek 云端回退遵循最小数据发送原则，并在首次使用前取得明确同意。
- JSON 备份不得包含 API key、环境变量、视频或音频。
- 应用不得尝试绕过 YouTube 的嵌入、登录、会员、地区或访问限制。

## 10. 技术边界

- **前端与本地服务**：Next.js + TypeScript。
- **视频播放**：YouTube IFrame Player API。
- **自动字幕获取**：可替换的 Caption Provider；首个实现可调用 `yt-dlp`。
- **手动字幕**：VTT/SRT Parser。
- **学习数据**：IndexedDB；必须有显式 schema version 和迁移策略。
- **基础词典**：可替换的 Dictionary Provider；首个实现为 Free Dictionary API。
- **AI**：可替换的 AI Provider；首选本地 OpenAI-compatible API，云端回退 DeepSeek。
- **媒体存储**：无。
- **服务端用户数据库**：无。

## 11. MVP 验收路径

以下流程必须全部通过：

1. 粘贴一个符合输入边界的 YouTube URL。
2. 系统在目标时间内完成校验、字幕获取和 Learning Sentence 生成。
3. 用户可识别字幕来自人工轨道还是自动轨道。
4. 点击任一句，视频准确跳转并播放该句。
5. 开启循环后，句尾暂停 3 秒并重复；关闭后继续下一句。
6. 连续操作 20 个句子，无明显错位或累积漂移。
7. 用户拆分、合并、编辑并调整一个句子的时间，然后恢复原始结果。
8. 点击单词或选择短语，得到与语境匹配的英文解释、例句和美式发音或 `en-US` 兜底。
9. 中文释义默认关闭，打开后可用。
10. 本地 AI 失败时，经首次授权回退 DeepSeek；两者都失败时显示基础词典结果。
11. 收藏 Word Lookup，并能从 Word Bank 跳回原句。
12. 删除来源视频后，收藏仍保留上下文但不再提供无效跳转。
13. 刷新浏览器并重启本地服务后，视频、进度、修订和收藏仍存在。
14. 导出 JSON 备份、清空学习数据、重新导入后，全部学习数据恢复，且备份中没有密钥。

## 12. 主要风险

1. **非官方字幕提取失效**：`yt-dlp` 可能因 YouTube 变化而失效。通过 Provider 隔离、依赖检查和手动字幕兜底降低影响。
2. **字幕质量和时间不准**：自动字幕可能缺标点、错词或错位。通过不静默改写、Local Revision 和恢复原始结果控制风险。
3. **IFrame 控制精度有限**：广告、网络、浏览器定时器和播放器行为可能影响 300 毫秒目标。需要用真实视频测试，并把外部限制与应用缺陷区分。
4. **免费词典覆盖不完整**：音频、例句和美式口音不保证完整。通过 Provider 隔离、`en-US` 语音合成和明确来源降低影响。
5. **AI 可能产生错误解释**：词典数据与 AI 辅助内容必须区分，AI 结果需要结构校验，失败时降级而非编造。
6. **浏览器数据可能被清除**：通过醒目的 JSON 备份能力降低风险；MVP 不承诺云端恢复。

## 13. 发布完成定义

MVP 只有在以下条件全部满足时才算完成：

- 第 11 节端到端验收路径全部通过。
- 至少使用人工字幕、自动字幕和手动字幕文件各完成一次真实导入测试。
- 至少使用短视频、60 分钟访谈和接近 3 小时上限的视频完成性能与列表流畅度测试。
- 本地 AI、DeepSeek 回退和 Dictionary only 三种状态均有自动化或可重复的验收步骤。
- 依赖缺失、视频不可嵌入、无字幕、网络失败和损坏备份都有明确中文错误体验。
- API key 不出现在浏览器网络响应、IndexedDB、JSON 备份或普通日志中。
- README 能让一位具备 Node.js 基础的开发者从空环境启动应用并完成首次导入。
